# Paramjot Singh

Personal site for Paramjot Singh, a software engineer. One page covering the OATI role, selected projects, and contact details.

## Run

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:4317](http://127.0.0.1:4317).

## Deploy

This is a Next.js app. Deploy on Vercel with the defaults (framework: Next.js). No environment variables are required.
